# Exploratory matched-start protection controls

The completed development run learned PathVQA while MedBook aggregate validation accuracy stayed approximately unchanged. That observation alone cannot identify a benefit from replay protection. This follow-up compares **two new loss conditions** against the preserved adaptive result; it does not rerun the completed method or retry any failed experiment under a new name.

Both new controls start from the exact same retained MedBook stage-one model as the adaptive stage, with seed 100, fresh AdamW, the same prepared PathVQA training split, 200 optimizer updates, eight GSPO trajectories, local batch four on two ranks, four accumulated microsteps and the previously used decoder/scorer/ZeRO settings. All prompts are fixed canonical. This matches the adaptive stage's actual empty cards; it does not claim successful dynamic strategy discovery.

1. **Plain GSPO:** no old-memory training access, replay loss, audit or proposer. Standard training parameters are preserved; this is a necessary comparison, not a baseline tuning search.
2. **Fixed-margin protection:** the same 338 immutable references, margin loss, replay sampler and audit frequency as the adaptive stage, but the loss coefficient is exactly **1** from the first update onward. Unit weight is the predefined constant-coefficient ablation, with no weight sweep. EMA audit observations are recorded but do not change this coefficient. This is an ablation of the studied mechanism, not an implementation of a separate published replay baseline.

The historical adaptive stage is the third comparison condition, using its already published final checkpoint and aggregate validation results. Its original OOM, discarded update, boundary restart, invalid proposals and replay-distinctness deviation remain part of the record. Controls deliberately match its actual with-replacement replay sampling rather than silently fixing the original deviation. Initial/final model checkpoints are retained; exact mid-arm optimizer/sampler recovery is still unavailable.

After both new conditions finish, both are evaluated on all 130 MedBook and 6,259 PathVQA validation questions with the frozen single-example canonical greedy evaluator. Report every condition's correct/n and both old/new task accuracies, including negative tradeoffs. There is no scalar endpoint chosen to favor a condition and no test-set access. This is an exploratory one-seed comparison planned after the original validation was known; it is not independent confirmatory evidence or a demonstration of PACT-full.

Equal new-task update counts do not imply equal compute or old-data access. Plain GSPO has no old-memory forwards. The fixed-margin condition entails 3,200 replay and 640 old-memory audit forwards across ranks by loop accounting, plus new-task GSPO work. It reuses the existing immutable memory rather than paying its construction cost again. Both controls omit the original adaptive stage's strategy audit/proposer overhead. Report actual training runtimes and these differences; do not infer full-method efficiency from the reused references or make the baseline consume padding work.

The controls run sequentially in fresh processes on the authorized two GPUs. A single independent supervisor covers both arms and their evaluation, with an eight-hour hard clock, a 40GB root guard and a 10GB per-file cap. The existing initial model/data are read-only; two new final models require approximately 15.1GB and estimated total new storage is 17GB. Any error, insufficient memory before a new phase, failed storage statistic or limit stops the current experiment with completed artifacts retained and no automatic retry. No historical files are deleted, and completed adaptive training remains closed. Aggregate results and permitted source/protocols will be released; private references, images/questions, per-example outputs and weights will not.
