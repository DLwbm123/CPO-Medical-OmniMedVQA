# Dermoscopy 复核修订

本修订在复核 TT-v0 的训练完成前生效，与 TT-GC 的前置检查、Fundus 开发和 Dermoscopy 确认协议同提交冻结。Fundus 阶段 B 的原判定仍为未通过。

Dermoscopy 全参数 TT-v0 照常训练并完成终点评测，报告原冻结的四项门槛。尚未开始的黑图门控组取消，以集中计算预算验证 TT-GC。复核只提供基线和机制诊断证据。旧脚本的 `direction` 不再用于判断测试时路线是否继续，旧源码与在跑进程保留。路线去向由 P0、开发试点和确认门槛依次决定。

Fundus 开发只训练 TT-GC，比较 Frozen 和已完成的全参数 TT-v0。该对照用于可行性判断，LoRA 与 M1、M2 的贡献在确认试点用同卡数的 TT-v0-LoRA 和 TT-GC 比较。开发结果仅作开发证据。

未改动设计的确认试点直接复用复核的 600 题、535 张图、同一 800 题训练流、已评分的 Frozen 和按图像成组的配对自助法。复核结果出现后冻结 TT-GC 的设计和超参。任何实质变更须由研究者决定，并将确认改为 XRay，从适配流中按图像分组预留约 600 个新问题。新版方法的确认证据不再取自 Dermoscopy 留出集。

M1 和 M2 仅修改组内标准化后的优势。受排除轨迹的 `completion_mask`、KL 和损失归一化保留。整步优势全零时跳过优化器。反事实来源排除确认留出集、阶段 A 验证和测试图像。若引用黑图门控旧实验的绝对 0.5 阈值排除比例，按合法选项数 K 分层。本次复核的黑图门控组无训练终点。

GPU 3、5 等当前复核释放后再运行 P0、Fundus 开发和确认。确认仅在前两关通过后启动。阶段 C 方法和新实验以确认门槛为准。
