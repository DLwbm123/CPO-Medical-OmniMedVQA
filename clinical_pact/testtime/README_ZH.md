# 医学 VQA 测试时持续强化学习

## 阶段 A

用未微调基座在 OmniMedVQA 八模态验证集上判断多数投票奖励是否有学习信号。
本阶段只做推理。运行前将 `protocol_a.json` 复制为运行目录内的 `protocol.json`。
以独立评测进程运行 `clinical_pact.testtime.supervise`，传入 `OUT`、`TT_DATA`
（包含八个 `MedicalVQA_*` 目录的数据根路径）、`TT_CHECKPOINT` 和一张 GPU。
运行目录生成 `progress.json`、`probe_result.json`、`PROBE_RESULT_ZH.md` 和状态记录。

- A1 对每个模态至多 1,000 题做全词表首 token 打分，多项式精确计算多数投票结果。
- A2 在 A1 的同一题池固定抽取 300 题，每题独立采样 16 次。用首 8 票估计 Maj@8。
  无效票保留在总票数中，计多数时跳过。并列视为错误。Pass@1 用 16 条中的正确比例估计。
- 每个模态核对 50 题的首 token。任一模态出现非裸字母、前向与贪心解码不同、
  多 token 答案达到 25%，或匹配题上三项关键指标的配对差超过 2.576 个标准误，
  所有模态统一改用 A2 判定。配对比较使用同一批 300 题。
- 至少 4 个模态同时达到 Maj@16 提升≥2 pp、10–14 票覆盖≥30% 和条件伪标签准确率≥70%，
  阶段 A 才通过。未达门槛时，用冻结的简短推理提示在同一批题上重做一次 A2。
- 输出字母边际分布、无效率、票数分布和 Pass@8/16。报告仅保留聚合数据。

阶段 A 已完成。原提示的真实采样为 0/8 个模态达标，简短推理提示为 4/8。
达到全部三项门槛的是 XRay、Fundus、OCT 和 Dermoscopy。Fundus 的 Maj@16
相对随机单次采样增幅最大，入选阶段 B。其 16 票覆盖为 32.00%，区间内伪标签准确率
为 85.42%。这些结果衡量冻结模型的投票信号，阶段 B 单独检验更新效果。
首次备用提示采样遇到统计量的 JSON 序列化错误。在保留首轮结果、原协议和原时钟后，
用相同题号与种子恢复补跑。 [阶段 A 完整结果](PROBE_RESULT_ZH.md)

## 后续训练的数据隔离与 C1′ 审计

训练输入由 `load_unlabeled` 从独立的预脱标文件读取，只接受题号、图像、题干、数据源。
CT 的 1,024 个预留题号在任何训练前从该脱标源生成，并从流中剔除。
阶段 B 和 C 的训练入口、参考题号清单及标签隔离冒烟测试应在对应阶段冻结后执行。

TT-full 在模态结束时从已流经、未进入回放记忆的题目固定抽取审计子集，用边界模型的
强制选项决策作锚点。后续每次全量审计在该子集上重新打分，按模态计算当前决策相对
锚点的翻转率，再用该翻转率更新对偶变量。审计题不进入回放梯度、Fisher 或奖励，
且不读取标签。若没有合法审计题，记录该模态审计不可用，保留其对偶变量。
`tt_memory.audit_items` 提供不相交的固定样本选择。控制器和训练接线属于阶段 C。
